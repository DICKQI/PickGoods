# 移动端导航重构

普通用户和管理员使用「社团 / 云展柜 / 整理 / 我的」，社团账号使用「社团 / 工作台 / 我的」。配置集中于 `frontend/src/navigation/mobile.ts`；管理后台与桌面端保持原有导航。

顶部便签栏高度为 44px 加顶部安全区，提供至少 44px 的触摸区域、横向滚动、选中标签回弹和减少动态效果支持；模块只有一个工作区时不渲染标签栏，社团目录的搜索栏因此直接位于页面顶部并横向铺满整行。内容切换淡入 160ms，底部选中背景滑动 280ms。谷仓搜索区上下间距均为 12px；草稿箱入口位于浮动操作菜单。谷仓滚动时底部导航带动画下移收起，停止滚动 500ms 后回升，减少动态效果模式下立即切换；其它页面底部导航常驻。

独立页面沿用原路由，云展柜内容沿用 `tab` 查询参数。移动工作区在会话内保留列表及滚动状态，身份变化时清空。编辑页面不进入列表缓存，手帐保留保存与离开保护，本次不优化其内部界面。

管理员的 IP与角色、品类新增操作移入搜索栏，移动工作区隐藏原标题行。IP 搜索栏在存在新增按钮时使用三列网格，避免第三个控件被原两列布局挤到下一行；该规则不应用于管理后台。

## 验证

在 `frontend/` 执行：

- `pnpm test:unit --run`
- `pnpm type-check`
- `pnpm build`
- 对修改的 Vue/TypeScript 文件执行 `pnpm exec eslint`，不自动修复。

`scripts/mobile-navigation-smoke.cjs` 使用 Playwright 和本机 Edge，在隔离上下文中模拟 API 与账号，检查 320/375/390/430px、四种身份、桌面布局、标签切换、底部导航及减少动态效果。管理员两个搜索栏额外检查 320/390px 下新增按钮居中且无横向溢出。

设置 `PLAYWRIGHT_MODULE` 为可用 Playwright 模块路径后执行 `node scripts/mobile-navigation-smoke.cjs`。截图、录屏和报告输出到被忽略的 `frontend/artifacts/mobile-navigation/`。这些产物使用模拟数据，不能作为真实后端权限、保存或所有弹层流程均已验收的证明。
